# 模块同一性核对清单

日期：2026-08-05
处理结果（2026-08-05 设计裁定后已落库）：金额展示拆出「还款方式选项」「剩余应还行动卡」；功能宫格拆出「更多记录宫格」；全部账单误标实例改挂新模块「待还汇总区」；主操作按钮**保持归并**（容器型操作组允许场景性单/双按钮变化——设计裁定）；灰区三项按建议处理（导航栏/分期计划列表改说明注明变体，半层优惠展示并入分期计划列表首期行）；孤儿模块已删除。模块总数 20 → 22。
方法：按「组件同一性」标准（结构/形态/状态机一致，仅内容不同），对全部 12 个多实例模块做**截图并排比对**（对比图见 `docs/module-audit/*.png`，可直接打开核对）。单实例模块（结果反馈、分期信息摘要、筛选栏、分期记录列表、分期详情字段、利率与费用说明）无比对需要。

## 需处理项（待设计定夺）

### 1. 金额展示（9 实例）— 拆出 2 个异类
对比图：`module-audit/amount-display.png`

- ✅ 频道首页×2 / 全部账单 / 本月账单 / 分期还款页 / 分期记录页 / 分期详情页（7 个）：同为「标题 + 大金额 + 辅助文案」的金额卡，对齐方式差异属排版变体，归并成立；
- ❌ **还款页实例**：实为「还款方式选项」——带单选框 ◯ + 金额 + 修改金额入口，是**可选择的表单项**（还款/分期还款/最低额还款三选一之一），非展示卡。建议拆出模块「还款方式选项」；
- ❌ **分期成功·未还清实例**：带「继续还款」CTA 按钮的行动卡（标题+金额+按钮+逾期提示），结构多了操作位。建议拆出「剩余应还行动卡」，或保留但标注为行动变体。

### 2. 主操作按钮（5 实例）— 拆出 1 个
对比图：`module-audit/action-buttons.png`

- ✅ 频道首页×2 / 全部账单 / 本月账单（4 个）：双按钮组（次级白 + 主橙带气泡）同构；「立即还款/提前还款」文案差异为内容级；
- ❌ **分期成功·已还清实例**：「返回首页」单个次级描边按钮，右下角落位——单按钮 vs 双按钮组不同构。建议拆出「返回首页按钮」。

### 3. 功能宫格（3 实例）— 处理 1 个
对比图：`module-audit/quick-grid.png`

- ✅ 频道首页×2：五宫格（可取现金…周账单）一致；
- ❌ **全部账单实例**：「更多记录」三宫格（带区块标题，内容为退款/还款/历史账单）。同为图标宫格形态族，但列数/内容/标题不同，且模块描述绑定了频道页内容。二选一：拆出「更多记录宫格」；或把模块泛化为「图标宫格」并改描述。

### 4. 账单列表（2 实例）— 发现误标注 ⚠️
对比图：`module-audit/bill-list.png`

- ✅ 本月账单实例：全部/分期/退款 tab + 账单条目列表，是真正的账单列表；
- ❌ **全部账单实例**：热区裁出来是「8月待还 20.50 / 全部待还 48.75」**金额汇总字段区**，不是账单列表——归类错误（与半层优惠误标同性质）。建议新建「待还汇总区」模块承接，或重新校准该页热区。

## 灰区项（建议保持归并 + 说明注明）

| 模块 | 差异点 | 建议 |
| --- | --- | --- |
| 导航栏（8 实例） | 频道首页×2 为品牌导航（logo+副标题+设置齿轮），其余为标准标题导航 | 保持同模块，说明注明「品牌变体」；导航属通用容器，拆分收益低 |
| 分期计划列表（2 实例） | 分期详情页版多期数进度（1/12期）与已还/待还状态标签 | 保持同模块，视为带还款状态的变体；可给模块补「已还/待还」状态枚举 |
| 优惠减免展示（3 实例） | 成功页/详情页为「label+橙色金额」字段行（同构）；半层首期为列表行内附属文字 | 半层实例建议并入「分期计划列表」的首期行（它本就是列表内容的一部分），字段行两例保持 |
