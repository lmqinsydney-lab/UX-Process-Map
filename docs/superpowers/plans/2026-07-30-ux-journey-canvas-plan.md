# 可视化体验链路 Demo · 实现计划

对应设计文档：`docs/superpowers/specs/2026-07-30-ux-journey-canvas-design.md`
原则：每个阶段结束时项目都可运行、可演示当阶段成果；阶段内任务按序执行。

## 阶段 0 · 工程脚手架与数据骨架

1. 初始化 Vite + React 18 + TypeScript 工程（根目录），引入 `@xyflow/react`。
2. `src/types/model.ts`：按设计文档第 3 节定义 `Project / ProcessNode / Page / PageState / ModuleDef / ModuleInstance / FlowEdge` 类型。
3. `src/data/project.json`：录入图二完整数据骨架——
   - 流程节点（5 个）：入口-增加按钮气泡引导 / 还款流程 / 分期还款页 / 分期结果页 / 分期记录·详情页。
   - 页面（约 10 个）：频道首页、全部账单、本月账单、还款页（4 状态：不展开期数 / 展开期数 / 未配置优惠-期数展开 / 未配置优惠-期数收起）、分期计划半层、线上页面、分期还款-频道首页、分期还款页、分期成功-已还清、分期成功-未还清、分期记录页、分期详情页。
   - 连线：主流程 + 状态间流转 + 至少各 1 条分支/异常/反向示例；事件与条件文案取图二标注，缺失处标 `TODO(待补)`。
   - 每页 3-6 个模块实例，模块全局定义含状态枚举；热区坐标先给估值，阶段 3 对照截图校准。
4. 占位图生成脚本 `scripts/gen-placeholders.mjs`：为每个「页面×状态」生成灰底线框 PNG（标注页面名+状态名）到 `assets/pages/<pageId>/<stateId>.png`，保证素材未到位时全链路可跑。
5. 验收：`npm run dev` 白屏工程可启动；`project.json` 通过类型校验脚本 `scripts/validate-data.mjs`。

## 阶段 1 · 画布全览

1. `CanvasOverview`：React Flow 实例 + 平移缩放 + MiniMap + Controls，浅色画布风格（借鉴图一顶栏布局，自绘顶栏：项目名 + 缩放显示）。
2. `ProcessGroupNode`：分组容器节点（底板 + 标题栏 + 节点级说明 tooltip），内部按数据横排页面卡片；布局坐标由 `project.json` 静态给出。
3. `PageCardNode`：缩略图 + 页面名 + 状态数角标；hover 提亮。
4. 状态展开（方案 C）：点击角标原位展开状态子卡片行（各状态缩略图 + 名称），显示状态间流转线；再点收起。展开时相邻节点不重排（预留足够间距）。
5. `FlowEdge`：四种类型样式（主流程实线粗 / 分支实线细 / 异常红虚线 / 反向灰虚线）+ 线上事件短标签；点击连线弹出气泡（事件 / 条件 / 类型 / 去向），点空白关闭。
6. 验收：全览完整渲染图二流程；角标展开收起流畅；任一连线可点出气泡；小地图与缩放可用。

## 阶段 2 · 聚焦态

1. 进入/退出：点击页面卡片 → React Flow `fitView` 动画推近节点 → 切入 `FocusView` 覆盖层；「返回全览」反向动画退出。
2. `PageViewer`（左侧）：按当前状态显示截图；模块热区虚线描边、hover 加深；选中后黑色半透明蒙层 + 选中模块镂空（CSS clip-path / 四矩形蒙层法）。
3. `DetailPanel · 页面详情`：状态 tab（联动左侧截图与热区）、模块构成列表（与热区双向联动高亮）、页面说明、线上已有页面、编辑按钮。
4. `DetailPanel · 模块详情`：模块状态 tab（切换更新说明文字）、通用说明 + 实例说明、「出现在哪些页面」跨页跳转、返回页面详情、编辑按钮。
5. `ChatEditStub`：两处编辑按钮共用，点击弹出对话输入框（可输入、发送后提示「Demo 占位，编辑能力后续版本开放」）。
6. 翻页：左右箭头沿主流程顺序切换页面（顺序由主流程边拓扑排序预计算）。
7. 验收：全览 ↔ 聚焦往返顺畅；热区/列表双向联动；聚光灯效果正确；状态切换同步；跨页跳转与翻页可用。

## 阶段 3 · 真实素材接入

1. 依赖用户：将图二原始大图放入 `assets/source/`（本阶段开始前提醒）。
2. `scripts/crop-pages.mjs`：按配置的裁切框批量裁出各「页面×状态」，覆盖占位图。
3. 对照真实截图校准全部热区坐标。
4. 产出 `docs/figma-export-guide.md`：Figma 导出命名清单（`<pageId>/<stateId>.png` 对照表），高清图按名覆盖即替换。
5. 验收：全览缩略图与聚焦态大图均为真实截图；热区与模块视觉边界吻合。

## 阶段 4 · 打磨与演示准备

1. 视觉打磨：连线走线避让、聚焦过渡动画时长与缓动、空态/加载态、面板滚动细节。
2. 演示路径自检：全览 → 状态展开 → 点边看条件 → 聚焦还款页 → 切状态 → 点模块（聚光灯）→ 模块详情 → 跨页跳转 → 对话编辑占位 → 返回全览，全程无断点。
3. `README.md`：本地启动方式 + 数据/素材维护说明。
4. `npm run build` 产出静态包，本地可直接打开演示。

## 里程碑与依赖

- 阶段 0-2 无外部依赖，可连续实施（Demo 骨架即可演示，占位图先行）。
- 阶段 3 依赖用户提供图二原图；Figma 高清图可后置，不阻塞演示。
- 每阶段完成即 git 提交一次。
